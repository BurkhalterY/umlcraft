## Editions, licensing and evaluation

- **Standard edition features** — Multi-platform (macOS, Windows, Linux), UML 2.x compliant, ERD, DFD, Flowchart, Mindmap, C4 model, Mermaid support, multiple windows, modern UX, dark and light themes, Retina/High-DPI, model-driven development, code generation and reverse engineering for Java, C, C++, C#, Python, JavaScript, TypeScript, PHP and SQL DDL, open APIs, third-party extensions, model validation, export to HTML docs, automatic updates. (https://docs.staruml.io/) — **UMLCraft:** ➖ n/a edition bundle; UMLCraft has no editions (of the listed items it covers only multi-platform builds, UML class/use case editing and a dark theme)
- **Professional edition features** — Everything in Standard plus SysML, BPMN, UI wireframe, AWS, GCP and Azure architecture diagrams, and code generation / reverse engineering for Ruby, Go, Kotlin, Rust, Dart and Swift. (https://docs.staruml.io/) — **UMLCraft:** ➖ n/a edition bundle; none of the Professional extras exist in UMLCraft

## Projects and files

- **Project file (.mdj)** — A project is the top-level element stored as a single `.mdj` file, usually organized as UMLModels, UMLPackages or UMLSubsystems. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ✅ present: opens and saves one .mdj project (Project > UMLModel/UMLPackage tree), unknown fields kept verbatim (src/app.rs:436, src/model.rs:155)
- **Model vs view** — A model element can have many view elements in one or several diagrams; renaming the model updates all views. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ✅ present: several views can reference one model (Explorer drag creates another view); name labels are re-read from the model on every layout, so a rename updates all views (src/canvas.rs:627, src/views.rs:1181)
- **Fragments (.mfj)** — Any element (typically UMLPackage/UMLModel/UMLSubsystem) can be exported as a separate `.mfj` fragment file and re-imported into a project. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ✅ present: any element can be exported as a `.mfj` and imported back into a project (src/fragment.rs:10, 20)
- **Profiles** — UML profiles extend UML for languages, methodologies or domains. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** 🟡 partial: profiles can be added and drawn in profile diagrams with metaclasses, stereotypes, extensions and generalizations, stereotypes are applied by name or from the Element Picker, and Model › Apply Profile adds the UML Standard Profile (src/ui.rs:294, 499-549, 1891-1896; src/app.rs:723-738, 1567); stereotype attributes do not become tags and stereotype icons are not drawn
- **New project** — `Ctrl+N` / File > New. (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** ✅ present: File > New and Ctrl+N, prompting to save changes (src/ui.rs:1709, src/ui.rs:2335)
- **New from template** — File > New From Template: UML Minimal, UML Conventional (Use Case/Analysis/Design/Implementation/Deployment models), 4+1 View Model, Rational (Rose approach), Data Model, AWS/Azure/GCP Architecture, BPMN Business Process Modeling, C4 Model, Wireframe Model. (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** 🟡 partial: File › New From Template › UML Minimal, UML Conventional, 4+1 View Model and Rational, each with the UML Standard Profile's stereotypes, and Data Model, C4 Model, Wireframe Model and BPMN Business Process Modeling (src/templates.rs:18-60, 121-150); no AWS, Azure or GCP templates

(https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** ✅ present: Ctrl+O / File > Open with .mdj filter; the Convert / Keep Colors prompt is V8-only and absent (src/ui.rs:2506)
