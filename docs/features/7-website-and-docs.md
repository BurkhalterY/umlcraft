## Editions, licensing and evaluation

- **Standard edition features** — Multi-platform (macOS, Windows, Linux), UML 2.x compliant, ERD, DFD, Flowchart, Mindmap, C4 model, Mermaid support, multiple windows, modern UX, dark and light themes, Retina/High-DPI, model-driven development, code generation and reverse engineering for Java, C, C++, C#, Python, JavaScript, TypeScript, PHP and SQL DDL, open APIs, third-party extensions, model validation, export to HTML docs, automatic updates. (https://docs.staruml.io/) — **UMLCraft:** ➖ n/a edition bundle; UMLCraft has no editions (of the listed items it covers only multi-platform builds, UML class/use case editing and a dark theme)
- **Professional edition features** — Everything in Standard plus SysML, BPMN, UI wireframe, AWS, GCP and Azure architecture diagrams, and code generation / reverse engineering for Ruby, Go, Kotlin, Rust, Dart and Swift. (https://docs.staruml.io/) — **UMLCraft:** ➖ n/a edition bundle; none of the Professional extras exist in UMLCraft

## Projects and files

- **Project file (.mdj)** — A project is the top-level element stored as a single `.mdj` file, usually organized as UMLModels, UMLPackages or UMLSubsystems. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ✅ present: opens and saves one .mdj project (Project > UMLModel/UMLPackage tree), unknown fields kept verbatim (src/app.rs:395, src/model.rs:155)
- **Model vs view** — A model element can have many view elements in one or several diagrams; renaming the model updates all views. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ✅ present: several views can reference one model (Explorer drag creates another view); name labels are re-read from the model on every layout, so a rename updates all views (src/canvas.rs:514, src/views.rs:686)
- **Fragments (.mfj)** — Any element (typically UMLPackage/UMLModel/UMLSubsystem) can be exported as a separate `.mfj` fragment file and re-imported into a project. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ✅ present: any element can be exported as a `.mfj` and imported back into a project (src/fragment.rs:10, 20)
- **Profiles** — UML profiles extend UML for languages, methodologies or domains. (https://docs.staruml.io/user-guide/basic-concepts/) — **UMLCraft:** ❌ missing: no profile support (profile elements in a file are kept, not usable)
- **New project** — `Ctrl+N` / File > New. (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** ✅ present: File > New and Ctrl+N, prompting to save changes (src/ui.rs:1360, src/ui.rs:1968)
- **New from template** — File > New From Template: UML Minimal, UML Conventional (Use Case/Analysis/Design/Implementation/Deployment models), 4+1 View Model, Rational (Rose approach), Data Model, AWS/Azure/GCP Architecture, BPMN Business Process Modeling, C4 Model, Wireframe Model. (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** 🟡 partial: File › New From Template › UML Minimal, UML Conventional, 4+1 View Model and Rational, without the UML Standard Profile (src/templates.rs:16)
- **Open project** — `Ctrl+O`; files saved by an older version prompt "Convert" (colors to color variables, so they follow themes) or "Keep Colors". (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** ✅ present: Ctrl+O / File > Open with .mdj filter; the Convert / Keep Colors prompt is V8-only and absent (src/ui.rs:2132)
- **Import StarUML 1 file** — File > Import > StarUML 1 File (.uml). (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** ❌ missing: no StarUML 1 (.uml) import
- **Save / Save As** — `Ctrl+S` / `Ctrl+Shift+S`. (https://docs.staruml.io/user-guide/managing-project/) — **UMLCraft:** ✅ present: Ctrl+S / Ctrl+Shift+S, Save As appends .mdj (src/ui.rs:1974, src/app.rs:447)

## Diagram editor (canvas)

(https://docs.staruml.io/user-guide/diagram-editor/) — **UMLCraft:** 🟡 partial: wheel, Shift+wheel and middle-button drag scroll; Ctrl+left-drag does not scroll (Ctrl+click toggles selection) (src/canvas.rs:528, src/canvas.rs:547, src/canvas.rs:760)

(https://docs.staruml.io/user-guide/diagram-editor/) — **UMLCraft:** ✅ present: minimap at the bottom right shows the diagram and viewport, click/drag scrolls there, and View › Minimap or Ctrl+Alt+M toggles it; no toolbar icon (src/canvas.rs:476, 684; src/ui.rs:1604, 2074)
- **Select mode** — Cursor icon in Toolbox or `Esc`. (https://docs.staruml.io/user-guide/diagram-editor/) — **UMLCraft:** ✅ present: cursor icon at the top of the Toolbox and Esc return to select mode (src/ui.rs:1173, src/canvas.rs:633)

- **Zoom** — `Ctrl++`, `Ctrl+-`, `Ctrl+0` actual size, `Ctrl+9` fit to window (and center), `Ctrl`/`Cmd`+wheel; zoom level shown in Statusbar. (https://docs.staruml.io/user-guide/diagram-editor/) — **UMLCraft:** ✅ present: Ctrl+= / Ctrl+- / Ctrl+0 keep the screen centre, Ctrl+9 fits the bounding box (never above 100%) and centres it, Ctrl+wheel zooms, zoom % in the status bar (src/ui.rs:2063-2092, src/canvas.rs:1844, src/canvas.rs:1856, src/canvas.rs:529, src/ui.rs:1285)
